# GoreeCloud Bookmark Browser Extension Branding

All branding authority belongs to `GoreeCloud/goreecloud-branding-assets`.

This extension is associated with GoreeCloud Bookmarks. Approved Bookmarks product artwork is stored at `products/bookmarks/app-icon.svg`. Any extension-specific logo, icon, badge, store artwork, or promotional asset must be created and approved in the unified branding repository before a synchronized derivative is added here.

Local artwork is a consumer derivative only and does not establish functionality, privacy, security, or release claims.
